Asset policy

Embed, do not link. Nothing the page needs at runtime is fetched from a third-party CDN. This applies to icons, fonts, JavaScript libraries and images where the platform allows.

Icons

  • Packs: Lucide, Heroicons and Font Awesome (free set) are all permitted, chosen per icon for fit, one pack per concept.
  • Delivery: server-rendered inline <svg>, currentColor, aria-hidden="true" and focusable="false" unless the icon is the only content, in which case the control carries a text label or aria-label.
  • No icon fonts. No sprite sheet request by default.
  • Sizing in em so icons scale with text; stroke icons use a 2px stroke.

JavaScript libraries

  • Bundle through the build; no <script src="https://...">.
  • Prefer no library: native <details>, CSS scroll snap, popover and the platform before adding a dependency. New packages need approval.
  • React runs only inside islands (see the islands and data map).

Images

  • Every image has width and height (no layout shift), alt text per the voice section, loading="lazy" below the fold and fetchpriority="high" on the LCP image only.
  • Responsive srcset and sizes from the platform image CDN; modern formats where available.
  • Brand images are shipped in the theme (assets/img); product images come from the catalogue.
  • Text is real text, never baked into an image (hero headlines, promo banners).

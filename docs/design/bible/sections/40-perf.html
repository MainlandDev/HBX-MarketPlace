Allowed external origins

  • BigCommerce image CDN (product and platform images) and the BigCommerce checkout.
  • Everything else is first party. Tracking and marketing origins are decided in the marketing brief and must load only after consent, deferred, never blocking render.

Rules

  • Critical CSS is inline per page type; the rest is a single cached stylesheet.
  • No render-blocking third-party anything. No web font blocking text.
  • Islands hydrate on visibility or interaction unless the page is unusable without them.
  • Run Lighthouse (npm run lighthouse) per page type before release and record results.

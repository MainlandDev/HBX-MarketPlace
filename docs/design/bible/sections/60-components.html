Buttons

Link styled as button
No JS: buttons submit forms or links navigate; no behaviour depends on script.
States: default, hover (1px lift, removed under reduced motion), focus-visible ring, disabled (60% opacity, never the only cue: text or a message explains why), loading (text changes, aria-busy).

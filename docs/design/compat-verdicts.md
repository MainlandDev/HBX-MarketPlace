# Compat verdicts for `assets/scss/tailwind/_tailwind.scss`

Date: 2026-11-26, after Citadel Sass was retired. Line numbers refer to `_tailwind.scss` as of this date. "Measured" evidence comes from the handoff reports (Edge, computed styles, round 3 to 5); the CSS equivalence checks for the one conversion were run against the dev server on 2026-11-26.

Why most rules stay: `important` is on (every utility is `!important`), and the store injects non-important `:not(#pseudoID)` and class rules. An important utility beats a store rule, so a class whose value the store also sets cannot become a utility without changing the rendered result. The rules below are only the ones where that, or JS/merchant markup, was measured.

## Question (c): is anything else convertible now that Citadel Sass is gone?

No. Citadel retirement removed Sass sources, not the reasons above. Every remaining class rule is kept for one of three reasons that Citadel did not influence: the store injects non-important rules on the same class (`important` makes a utility beat them), merchant or third-party markup cannot take utilities, or the cascade-layer order differs. The `@apply` property lists of the kept rules could still be shortened, but that does not change what stays.
